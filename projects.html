Personal project, in daily use

Nox

A voice assistant for Windows that answers only to my voice. Speech is transcribed on my own GPU; a router handles simple requests locally and sends the rest to a headless Claude Code process limited to an allowlist of tools.

Python, PySide6 (Qt), faster-whisper (CUDA), Resemblyzer, edge-tts, Claude Code headless with MCP, Postgres (Supabase), Strava API

How it is built

A voice assistant for Windows that lives as an island at the top of the screen and answers only to my voice. Listening is local: wake word, Whisper on the GPU and a speaker check, so only text reaches the model. A router sends simple requests (open a file, take a note, log food) to local shortcuts, which took opening a file from 11.7 seconds to 0.1; everything else goes to a persistent headless Claude Code process that picks the model per request. Security was most of the work: connectors come from an allowlist, about 120 deny rules block anything that sends, deletes or pays, emails and web pages are treated as data and never as instructions, secrets live in the Windows Credential Manager, and its database role is read-only with row-level security. The repository is a showcase: architecture, security model and demo, with the source kept private.

Ask my CV

The assistant in the terminal on my home page. A small Python service on my own server answers only from my CV and streams the reply.

Python, Gemini API, nginx, systemd, JavaScript, Streaming

How it is built

An AI assistant built into the terminal on my home page. Visitors ask about my experience in English, Spanish or Catalan and the answer streams in live, written only from my CV. A small Python service (standard library, no dependencies) runs behind nginx on my own VPS and calls the Gemini API with my profile as context. Production details on a zero budget: the prompt keeps it on topic and treats every message as a question, never as instructions; length limits, per-visitor and daily caps and nginx rate limiting keep it safe and free to run; questions are never logged; and systemd runs it sandboxed, restarting it on every deploy.

Case study

GenAI Data Platform

Business users ask in plain language. An LLM writes the SQL, a governed semantic layer validates it, and the result is published as Metabase dashboards.

Python, PostgreSQL, Docker, LLM text-to-SQL, Metabase API, Streamlit

How it is built

Natural-language analytics platform built during a corporate GenAI mentorship program. Business users ask questions in plain language; an LLM translates them into SQL, a governed semantic layer validates every query (read-only, row-level security), and the result is executed on a PostgreSQL warehouse and published automatically as charts and dashboards in Metabase through its REST API. I authored the semantic business-term definitions, built the Metabase integration bridge and automated dashboard composition, and developed the Streamlit web interface — working hands-on with AI agents as part of the development workflow.

Retired, with a post-mortem

Polymarket trading bot

Two Claude agents built and reviewed trading strategies. Right 81% of the time in simulation and 41% with real money, so I shut it down.

Claude agents, Docker, Hetzner VPS

How it is built

A bot that traded prediction markets, built by two Claude agents: one implemented strategies and the other reviewed them. It was right 81% of the time in simulation and 41% with real money, so I shut it down. What I kept from it: a backtest only proves the simulator, so validate with small real stakes before scaling anything.
